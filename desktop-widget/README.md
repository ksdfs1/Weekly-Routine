# Weekly Routine 데스크톱 위젯 (Windows)

웹앱의 위젯 보기(`https://ksdfs1.github.io/Weekly-Routine/?view=widget`)를 테두리 없는 작은 창으로 바탕화면에 붙여 둡니다. 위젯에는 '지금' 상태와 월~일 7개의 원형 시계가 나옵니다.

- 다른 창들보다 항상 뒤에 있고, Win+D(바탕화면 보기)를 눌러도 사라지지 않습니다.
- 30초마다 다시 그리고, 10분마다 서버에서 최신 루틴을 불러옵니다. 절전에서 깨어날 때도 새로고침합니다.
- 작업 표시줄과 Alt+Tab에는 나타나지 않습니다. 메뉴는 **트레이 아이콘**(시계 옆 ^ 영역)이나 **위젯 우클릭**으로 엽니다.
- **이동·크기 조절**: 위젯에 마우스를 올리면 위쪽 가운데에 **⠿ 이동** 손잡이, 오른쪽 아래에 크기 조절 그립이 나타납니다. 끌면 바로 옮기거나 크기를 바꿀 수 있고, 위치와 크기는 자동 저장됩니다.
- **케이스 선택**: 각 요일 시계 아래 드롭다운에서 케이스를 바꿀 수 있습니다. 트레이 메뉴의 **편집 토큰 설정…**에 웹앱의 편집 토큰을 넣어 두면 서버에 저장돼 모든 기기에 반영되고, 토큰이 없으면 이 PC에서만 적용됩니다.
- **시계 구간 강조**: 시계의 한 구간을 누르면 그 구간이 커지면서 상태와 시간대가 표시됩니다.
- **자동 실행**: 처음 실행하면 Windows 시작 시 자동 실행이 켜져서, PC를 재부팅해도 위젯이 다시 뜹니다. 트레이 메뉴에서 끌 수 있습니다.

## 트레이 메뉴

| 항목 | 동작 |
|---|---|
| 위치·크기 조정 | 켜면 주황색 테두리가 생깁니다. 위쪽 띠를 끌면 이동하고, 테두리를 끌면 크기가 바뀝니다. 다시 누르면 고정되고 위치가 저장됩니다. (마우스를 올리면 나오는 손잡이·그립으로도 됩니다.) |
| 새로고침 | 최신 루틴을 다시 불러옵니다(트레이 아이콘을 더블클릭해도 같음). |
| 브라우저에서 앱 열기 | 편집할 수 있는 원래 웹앱을 엽니다. |
| 편집 토큰 설정… | 위젯에서 바꾼 케이스를 서버에 저장할 때 쓸 편집 토큰을 넣습니다. 비우면 토큰을 지웁니다. |
| Windows 시작 시 자동 실행 | 로그인할 때 자동으로 실행합니다(`HKCU\...\Run`에 등록). 처음 실행할 때 자동으로 켜집니다. |
| 종료 | 위젯을 닫습니다. |

기본 크기는 1280×340입니다. 위치와 크기는 `%APPDATA%\WeeklyRoutineWidget\settings.json`에 저장됩니다.

## 빌드

[.NET 8 SDK](https://dotnet.microsoft.com/download)가 필요합니다(`winget install Microsoft.DotNet.SDK.8`). WebView2 런타임은 Windows 11에 기본으로 들어 있습니다.

```bash
cd desktop-widget
dotnet run                     # 바로 실행해보기

# exe 하나로 만들기 → bin/Release/net8.0-windows/win-x64/publish/WeeklyRoutineWidget.exe
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained false
```

만든 exe를 원하는 폴더(예: `%LOCALAPPDATA%\Programs\WeeklyRoutineWidget\`)에 복사하고 한 번 실행하면 자동 실행까지 등록됩니다. 자동 실행에는 실행한 exe의 경로가 등록되고, exe를 옮긴 뒤 새 위치에서 한 번 실행하면 경로도 따라 바뀝니다.
