# Weekly Routine 안드로이드 앱

휴대폰에서는 이 앱 하나로 시현·편집, 홈 화면 위젯, 상태 변경 알림을 모두 씁니다.

- 앱을 열면 웹앱(`index.html`, PC와 같은 화면)이 앱 안의 WebView로 뜹니다. 시현·편집 기능은 PC 웹과 똑같고, 웹앱을 고쳐 push하면 앱에도 바로 반영됩니다.
- 위젯과 알림은 네이티브로 동작하고, 위젯이나 알림을 누르면 이 앱이 열립니다.
- 예전에 Chrome으로 설치한 PWA 아이콘은 이제 지워도 됩니다.

## 기능

- **시현·편집**: PC 웹앱과 같습니다. 앱 안에서 저장하면 **위젯과 알림 예약에 바로 반영**됩니다.
- **알림 · 앱 설정**: 앱 위쪽의 **⚙ 알림** 버튼을 누르면 나옵니다. 알림 켜기/끄기, **소리**, **진동**, 미지정 시간 알림, 테스트 알림, 시스템 알림 설정, 권한(알림·정확한 알람·배터리 최적화) 안내가 있습니다.
- **편집 토큰 공유**: 앱에서 편집 잠금을 풀면(토큰 입력) 위젯의 케이스 선택도 같은 토큰을 씁니다. 전에 앱 설정에 넣어 둔 토큰은 앱을 처음 열 때 자동으로 넘어옵니다.

- **4x2 홈 화면 위젯 '오늘 루틴'**: 왼쪽(40%)에 현재 시각과 오늘의 원형 시계(가운데에 지금 상태와 남은 시간), 오른쪽(60%)에 **지금** 할 일(예: `업무 · 팀 회의`, `12:00까지 · 다음: 점심식사 12:00`), 오늘 블록 목록을 보여줍니다. 지금 진행 중인 블록은 강조됩니다. 위젯은 블록이 바뀌는 순간과, 화면이 켜져 있는 동안 1분마다 다시 그립니다(폰이 대기 중일 때는 깨우지 않아 배터리를 쓰지 않습니다).
- **상태 변경 알림**: 루틴상 지금 할 일이 바뀌는 순간(블록 시작, 빈 시간 시작, 자정에 다음 날 루틴으로 바뀔 때) 알림을 보냅니다.
  - 알림은 폰 안에서 알람으로 예약하므로 인터넷이 없어도 옵니다.
  - 이어지는 두 블록의 카테고리와 메모가 같으면 한 번만 알립니다.
- **요일 넘기기**: 위젯의 ◀ ▶ 버튼이나 아래쪽 요일 띠(월~일)를 누르면 다른 요일의 시계와 블록 목록을 볼 수 있습니다. 2분쯤 지나면 오늘로 돌아옵니다. ('지금' 줄은 항상 오늘 기준입니다.)
  - 안드로이드 홈 화면 위젯은 시스템이 좌우 스와이프를 받지 않아서(밀면 런처가 홈 화면 페이지를 넘김) 버튼과 요일 띠로 넘깁니다.
- **구간 강조**: 오른쪽 블록 목록에서 한 줄을 누르면 시계에서 그 구간이 살짝 커지고 나머지는 어두워지며, 가운데에 상태·시간대·메모가 나옵니다. 같은 줄을 다시 누르거나 1~2분 지나면 원래대로 돌아옵니다. (홈 화면 위젯은 누른 위치를 알 수 없어서 시계 대신 목록 줄로 고릅니다. 앱을 열려면 위젯 배경을 누르세요.)
- **위젯에서 케이스 선택**: 위젯 위쪽의 **요일 · 케이스 ▾**를 누르면 지금 보고 있는 요일의 케이스 목록이 뜨고, 고르면 바로 바뀝니다.
  - 앱에서 편집 잠금이 풀려 있으면(편집 토큰), 바꾼 케이스가 서버에 저장돼 웹앱·PC 위젯에도 똑같이 반영됩니다(오프라인이면 연결되는 대로 저장).
  - 토큰이 없으면 이 폰에서만 적용됩니다.
- **동기화**: 앱을 열거나 앱의 **↻ 새로고침**을 누를 때, 그리고 1시간마다 서버(`GET /state`)에서 루틴을 불러옵니다. 위젯의 ↻ 버튼으로도 불러올 수 있습니다.

## 빌드 & 설치

1. [Android Studio](https://developer.android.com/studio)를 설치합니다(`winget install Google.AndroidStudio`). 처음 실행할 때 나오는 SDK 설치 마법사를 끝까지 진행합니다.
2. Android Studio에서 **Open**을 눌러 이 `android/` 폴더를 엽니다. Gradle Sync가 끝날 때까지 기다립니다.
3. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**를 실행하면 `app/build/outputs/apk/debug/app-debug.apk`가 만들어집니다.
   - 또는 폰을 USB 디버깅으로 연결하고 ▶ Run을 누르면 바로 설치됩니다.
   - 명령줄로 빌드할 수도 있습니다: `JAVA_HOME`을 Android Studio의 `jbr` 폴더로 지정한 뒤 `android/`에서 `gradlew assembleDebug`를 실행합니다.
4. APK 파일을 폰으로 옮겨서 실행합니다. "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용합니다.
5. 앱을 한 번 열어 **알림 권한을 허용**합니다. 삼성 폰이라면 배터리 설정을 '제한 없음'으로 바꿔 두세요(**⚙ 알림** 패널의 권한 섹션에서 안내). 처음 한 번은 인터넷 연결이 필요하고, 그 뒤로는 오프라인에서도 마지막 화면이 열립니다.
6. 홈 화면을 길게 누르고 **위젯 → Weekly Routine → 오늘 루틴**을 추가합니다.

## 소리·진동 설정에 대해

Android 8부터는 알림의 소리와 진동을 '알림 채널' 단위로 시스템이 관리합니다. 그래서 이 앱은 **소리+진동 / 소리만 / 진동만 / 무음** 채널 4개를 만들어 두고, 설정에서 켠 조합에 맞는 채널로 알림을 보냅니다. 알림음 종류를 바꾸고 싶다면 설정의 **시스템 알림 설정 열기**에서 해당 채널을 골라 바꾸면 됩니다. 진동은 따로 패턴을 정하지 않아서 휴대폰의 진동 설정(길이·세기)을 그대로 따릅니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `RoutineLogic.kt` | `index.html`의 `activeCase` / `segmentsWithGaps` / `nowStatus`를 옮긴 코드. 웹앱 로직을 바꾸면 여기도 맞춰야 합니다. |
| `RoutineRepository.kt` | 서버에서 불러오기, 파일 캐시, 설정값, 케이스 저장 |
| `CasePickerActivity.kt` | 위젯의 케이스 선택 대화상자, 서버 저장(`CaseSaveWorker`) |
| `RoutineWidgetProvider.kt` | 위젯과 블록 목록(`RoutineListService`) |
| `ClockRenderer.kt` | 위젯의 원형 시계 비트맵 |
| `TransitionScheduler.kt` | 다음 경계 시각 알람, 알림 발송, 재부팅 후 재예약 |
| `Notifier.kt` | 알림 채널과 알림 내용 |
| `RoutineApp.kt` | 앱 시작 시 채널 생성, 1시간 주기 동기화(`SyncWorker`) |
| `MainActivity.kt` | 앱 화면: 웹앱을 띄우는 WebView와 JS 브리지(`WRNative`), 파일 가져오기·내보내기, 권한 요청 |
