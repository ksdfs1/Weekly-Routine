# Weekly Routine 안드로이드 동반 앱

PWA만으로는 안드로이드 홈 화면 위젯을 만들 수 없어서, 위젯과 알림만 담당하는 작은 네이티브 앱을 따로 둡니다. 편집과 전체 화면 보기는 그대로 웹앱(PWA)에서 합니다. 위젯이나 알림을 탭하면 웹앱이 열립니다.

## 기능

- **4x2 홈 화면 위젯 '오늘 루틴'**: 오늘의 원형 시계, **지금** 할 일(예: `업무 · 팀 회의`, `12:00까지 · 다음: 점심식사 12:00`), 오늘 블록 목록을 보여줍니다. 지금 진행 중인 블록은 강조됩니다. 위젯은 블록이 바뀌는 순간마다 다시 그립니다. 배터리를 아끼려고 매분 바뀌는 카운트다운 대신 "~까지"로 표시합니다.
- **상태 변경 알림**: 루틴상 지금 할 일이 바뀌는 순간(블록 시작, 빈 시간 시작, 자정에 다음 날 루틴으로 바뀔 때) 알림을 보냅니다.
  - 알림은 폰 안에서 알람으로 예약하므로 인터넷이 없어도 옵니다.
  - 이어지는 두 블록의 카테고리와 메모가 같으면 한 번만 알립니다.
- **설정**(앱 아이콘): 알림 켜기/끄기, **소리**, **진동**, 미지정 시간 알림, 테스트 알림, 권한 안내, 지금 동기화.
- **동기화**: 웹앱과 같은 서버(`GET /state`)에서 1시간마다 루틴을 불러옵니다. 위젯의 ↻ 버튼이나 설정의 **지금 동기화**로 바로 불러올 수도 있습니다. 이 앱은 읽기만 하고 서버에 저장하지는 않습니다.

## 빌드 & 설치

1. [Android Studio](https://developer.android.com/studio)를 설치합니다(`winget install Google.AndroidStudio`). 처음 실행할 때 나오는 SDK 설치 마법사를 끝까지 진행합니다.
2. Android Studio에서 **Open**을 눌러 이 `android/` 폴더를 엽니다. Gradle Sync가 끝날 때까지 기다립니다.
3. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**를 실행하면 `app/build/outputs/apk/debug/app-debug.apk`가 만들어집니다.
   - 또는 폰을 USB 디버깅으로 연결하고 ▶ Run을 누르면 바로 설치됩니다.
   - 명령줄로 빌드할 수도 있습니다: `JAVA_HOME`을 Android Studio의 `jbr` 폴더로 지정한 뒤 `android/`에서 `gradlew assembleDebug`를 실행합니다.
4. APK 파일을 폰으로 옮겨서 실행합니다. "출처를 알 수 없는 앱 설치"를 허용하라는 안내가 나오면 허용합니다.
5. 앱을 한 번 열어 **알림 권한을 허용**합니다. 삼성 폰이라면 배터리 설정을 '제한 없음'으로 바꿔 두세요(설정 화면의 권한 섹션에서 안내).
6. 홈 화면을 길게 누르고 **위젯 → Weekly Routine → 오늘 루틴**을 추가합니다.

## 소리·진동 설정에 대해

Android 8부터는 알림의 소리와 진동을 '알림 채널' 단위로 시스템이 관리합니다. 그래서 이 앱은 **소리+진동 / 소리만 / 진동만 / 무음** 채널 4개를 만들어 두고, 설정에서 켠 조합에 맞는 채널로 알림을 보냅니다. 알림음 종류를 바꾸고 싶다면 설정의 **시스템 알림 설정 열기**에서 해당 채널을 골라 바꾸면 됩니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `RoutineLogic.kt` | `index.html`의 `activeCase` / `segmentsWithGaps` / `nowStatus`를 옮긴 코드. 웹앱 로직을 바꾸면 여기도 맞춰야 합니다. |
| `RoutineRepository.kt` | 서버에서 불러오기, 파일 캐시, 설정값 |
| `RoutineWidgetProvider.kt` | 위젯과 블록 목록(`RoutineListService`) |
| `ClockRenderer.kt` | 위젯의 원형 시계 비트맵 |
| `TransitionScheduler.kt` | 다음 경계 시각 알람, 알림 발송, 재부팅 후 재예약 |
| `Notifier.kt` | 알림 채널과 알림 내용 |
| `RoutineApp.kt` | 앱 시작 시 채널 생성, 1시간 주기 동기화(`SyncWorker`) |
| `SettingsActivity.kt` | 설정 화면 |
