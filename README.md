# Weekly Routine

월~일 요일별 루틴을 5분 단위로 편집하고, 24시간짜리 원형 시계(도넛 차트)로 시현하는 개인용 웹앱입니다. 프레임워크 없이 순수 HTML/CSS/JS 한 파일로 만들어졌고, GitHub Pages에 올려 노션(Notion) 등에 실제로 인라인 임베드할 수 있습니다.

**🔗 데모(예시 데이터, 저장 안 됨): https://ksdfs1.github.io/Weekly-Routine/demo/**

> 위 데모는 실제로 쓰는 계정/백엔드와 분리된 별도 페이지입니다. 예시 데이터만 보여주고, 여기서 뭘 바꿔도 어디에도 저장되지 않습니다.

## 주요 기능

- **5분 단위 편집** — 요일마다 시작/종료 시각을 5분 단위로 지정해 블록을 추가·수정·삭제.
- **케이스(변형) 지원** — 하루에 "사무실 출근 / 재택근무 / 휴식" 같은 여러 시나리오를 만들어두고 골라서 시현.
- **24시간 원형 시계 시현** — 카테고리별 색상으로 구분된 도넛 차트. 오늘 날짜면 현재 시각 바늘도 함께 표시.
- **일간 / 주간 시현 전환** — 일간은 요일 탭 전환 + 스와이프로 요일 넘기기, 주간은 월~일을 한 줄로 두고 좌우 스크롤(마우스 드래그 / 터치 모두 지원).
- **카테고리 관리** — 색상·이름을 자유롭게 편집, 사용 중인 카테고리는 삭제 방지.
- **크로스 디바이스 동기화** — Cloudflare Worker + KV 백엔드에 저장해서 어느 기기·브라우저에서 열어도 같은 데이터가 보임.
- **토큰 기반 편집 잠금** — 조회(시현)는 누구나 가능하고, 편집은 발급받은 토큰을 입력해야 가능.
- **JSON 내보내기/가져오기** — 로컬 파일로 백업·복원.
- **노션 인라인 임베드** — GitHub Pages는 `X-Frame-Options`를 보내지 않아 노션에 진짜로 인라인 삽입됨(iframe 차단 없음).
- **다크 네이비 테마** — 색맹 접근성을 고려해 검증한 카테고리 색상 팔레트.

## 기술 스택

| 구성 요소 | 선택 |
|---|---|
| 프론트엔드 | 순수 HTML/CSS/JS 단일 파일(`index.html`), 빌드 과정 없음 |
| 호스팅 | GitHub Pages |
| 백엔드 | Cloudflare Workers + KV (`worker/`) |
| 인증 | Bearer 토큰 1개 (쓰기만 보호, 읽기는 공개) |

## 폴더 구조

```
index.html            앱 전체(HTML+CSS+JS)
worker/
  src/index.js         Cloudflare Worker API (GET/POST /state)
  wrangler.toml         Worker 설정 (KV 네임스페이스 바인딩)
AI-BUILD-GUIDE.md      이 앱을 다른 계정/PC에서 AI로 똑같이 재현하기 위한 전체 스펙 문서
```

## 이 앱을 그대로 다시 만들고 싶다면

**[`AI-BUILD-GUIDE.md`](./AI-BUILD-GUIDE.md)** 를 참고하세요. 데이터 모델, 기능 스펙, Worker 전체 코드, 처음부터 구축하는 13단계 절차, 그리고 Claude Code 같은 AI 코딩 어시스턴트에게 그대로 붙여넣어 사용할 수 있는 요청 예시까지 담겨 있습니다. 이 문서 하나만 있으면 다른 컴퓨터·다른 계정에서도 AI의 도움으로 동일한 앱을 새로 구축할 수 있습니다.

## 보안 노트

- 편집용 `WRITE_TOKEN`은 코드나 저장소에 절대 커밋하지 않고, Cloudflare Worker의 secret으로만 관리합니다.
- 브라우저는 사용자가 입력한 토큰을 `localStorage`에만 저장하며, 저장 요청 때마다 `Authorization` 헤더로 전송할 뿐 코드에는 남지 않습니다.
- 조회(`GET /state`)는 의도적으로 공개되어 있고, 저장(`POST /state`)만 토큰으로 보호됩니다.
