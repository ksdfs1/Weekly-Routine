# Weekly Routine

월~일 요일별 루틴을 5분 단위로 편집하고, 24시간짜리 원형 시계(도넛 차트)로 시현하는 개인용 웹앱입니다. 프레임워크 없이 순수 HTML/CSS/JS 한 파일로 만들어졌고, GitHub Pages에 올려 노션(Notion) 등에 실제로 인라인 임베드할 수 있습니다.

**🔗 데모(예시 데이터, 저장 안 됨): https://ksdfs1.github.io/Weekly-Routine/demo/**

> 위 데모는 실제로 쓰는 계정/백엔드와 분리된 별도 페이지입니다. 예시 데이터만 보여주고, 여기서 뭘 바꿔도 어디에도 저장되지 않습니다.

## 주요 기능

- **5분 단위 편집** — 요일마다 시작/종료 시각을 5분 단위로 지정해 블록을 추가·수정·삭제.
- **케이스(변형) 지원** — 하루에 "사무실 출근 / 재택근무 / 휴식" 같은 여러 시나리오를 만들어두고 골라서 시현.
- **24시간 원형 시계 시현** — 카테고리별 색상으로 구분된 도넛 차트. 오늘 날짜면 현재 시각 바늘도 함께 표시.
- **구간 강조** — 시계의 한 구간(예: 12:00~13:00)을 누르면 그 구간이 살짝 커지고, 가운데에 그 구간의 상태(예: "업무")와 시간대·메모가 나옴. 나머지 구간은 어둡고 흐릿해짐. 같은 구간이나 가운데를 다시 누르면 원래대로.
- **'지금' 상태 표시** — 화면 위쪽에 루틴상 지금 해야 할 일(예: "업무 · 팀 회의, 1시간 20분 남음, 다음: 점심 12:00")을 항상 보여주고, 오늘 시계 가운데에도 현재 카테고리와 남은 시간을 표시.
- **일간 / 주간 시현 전환** — 일간은 요일 탭 전환 + 스와이프로 요일 넘기기, 주간은 월~일을 한 줄로 두고 좌우 스크롤(마우스 드래그 / 터치 모두 지원).
- **카테고리 관리** — 색상·이름을 자유롭게 편집, 사용 중인 카테고리는 삭제 방지.
- **크로스 디바이스 동기화** — Cloudflare Worker + KV 백엔드에 저장해서 어느 기기·브라우저에서 열어도 같은 데이터가 보임. 상단 **↻ 새로고침** 버튼으로 페이지를 다시 열지 않고도 최신 내용을 불러옴.
- **토큰 기반 편집 잠금** — 조회(시현)는 누구나 가능하고, 편집은 발급받은 토큰을 입력해야 가능.
- **JSON 내보내기/가져오기** — 로컬 파일로 백업·복원.
- **노션 인라인 임베드** — GitHub Pages는 `X-Frame-Options`를 보내지 않아 노션에 진짜로 인라인 삽입됨(iframe 차단 없음).
- **다크 네이비 테마** — 색맹 접근성을 고려해 검증한 카테고리 색상 팔레트.
- **휴대폰 앱으로 설치(PWA)** — 홈 화면에 아이콘으로 설치하면 주소창 없는 전체화면 앱으로 열리고, 오프라인에서도 마지막으로 불러온 루틴이 보임.
- **안드로이드 홈 화면 위젯 + 상태 변경 알림** — 동반 앱(`android/`)을 설치하면 4x2 위젯에 현재 시각, 오늘 루틴(시계 가운데에 지금 상태와 남은 시간), '지금' 할 일이 나오고, 할 일이 바뀔 때마다 알림이 옴(소리·진동 각각 설정 가능). ◀ ▶·요일 띠로 다른 요일을 보고, 블록 목록을 누르면 시계에서 그 구간이 강조되고, 위젯에서 바로 케이스를 바꿀 수 있음.
- **PC 바탕화면 위젯** — `desktop-widget/` 앱이 휴대폰 위젯과 같은 화면(현재 시각 + 오늘 시계, 케이스 선택, '지금', 블록 목록)을 바탕화면에 띄워 둠. 마우스로 좌우로 끌면 요일 이동, 마우스를 올리면 '앱 열기' 버튼, 끌어서 이동·크기 조절, Windows 시작 시 자동 실행. 웹앱의 `?view=widget` 보기를 사용.

## 휴대폰 앱으로 설치하기

- **Android**: 안드로이드 앱(`android/`) 하나로 시현·편집·위젯·알림을 모두 씁니다. 앱 안에 같은 웹앱이 들어 있습니다. 설치 방법은 [`android/README.md`](./android/README.md)를 보세요.
- **iPhone (Safari)**: 사이트 접속 → 아래쪽 공유 버튼 → **"홈 화면에 추가"**(PWA).
- PWA는 안드로이드 Chrome에서도 **"앱 설치"**로 쓸 수 있지만, 위젯·알림이 필요하면 안드로이드 앱을 쓰세요.

설치한 앱에서도 편집·저장·시현이 모두 동일하게 동작하고, 저장하면 다른 기기와 동기화됩니다. 다른 기기에서 저장한 내용은 상단의 **↻ 새로고침** 버튼으로 바로 불러올 수 있습니다(웹·노션 임베드·설치한 앱 모두 동일). 저장소 코드를 수정해 push하면 설치된 앱에도 다음 실행 때 자동 반영됩니다.

> **iPhone 참고**: 홈 화면에 추가한 앱은 Safari와 저장공간이 분리되어 있어서, 처음 한 번은 앱 안에서 편집 토큰을 다시 입력해야 합니다.

## 위젯 · 알림

| 대상 | 내용 | 설치 방법 |
|---|---|---|
| 안드로이드 | 앱(웹앱 + 알림 설정) + 4x2 위젯(오늘 루틴) + 상태 변경 알림 | [`android/README.md`](./android/README.md) — Android Studio로 APK 빌드 후 설치 |
| Windows PC | 바탕화면 위젯(휴대폰 위젯과 같은 오늘 루틴, 좌우로 끌어 요일 이동) | [`desktop-widget/README.md`](./desktop-widget/README.md) — .NET 8로 exe 빌드 |

PC 위젯이 보여주는 화면은 `https://ksdfs1.github.io/Weekly-Routine/?view=widget`이라 브라우저에서도 바로 열어볼 수 있습니다. 두 위젯 모두 웹앱과 같은 서버에서 루틴을 읽고, 블록 편집은 웹앱에서 합니다.

위젯에서는 **케이스만** 바꿀 수 있습니다. 위젯에 편집 토큰을 넣어 두면(안드로이드: 앱 설정 / PC: 트레이 메뉴 **편집 토큰 설정…**) 바꾼 케이스가 서버에 저장돼 웹앱과 다른 위젯에도 그대로 반영되고, 토큰이 없으면 그 기기에서만 적용됩니다.

## 기술 스택

| 구성 요소 | 선택 |
|---|---|
| 프론트엔드 | 순수 HTML/CSS/JS 단일 파일(`index.html`), 빌드 과정 없음 |
| 호스팅 | GitHub Pages |
| 백엔드 | Cloudflare Workers + KV (`worker/`) |
| 인증 | Bearer 토큰 1개 (쓰기만 보호, 읽기는 공개) |
| 안드로이드 위젯·알림 | Kotlin 네이티브 앱 (`android/`, AppWidget + AlarmManager + WorkManager) |
| PC 위젯 | .NET 8 WinForms + WebView2 (`desktop-widget/`) |

**[`AI-BUILD-GUIDE.md`](./AI-BUILD-GUIDE.md)** 를 참고하세요. 데이터 모델, 기능 스펙, Worker 전체 코드, 처음부터 구축하는 14단계 절차, 그리고 Claude Code 같은 AI 코딩 어시스턴트에게 그대로 붙여넣어 사용할 수 있는 요청 예시까지 담겨 있습니다. 이 문서 하나만 있으면 다른 컴퓨터·다른 계정에서도 AI의 도움으로 동일한 앱을 새로 구축할 수 있습니다.

## 보안 노트

- 편집용 `WRITE_TOKEN`은 코드나 저장소에 절대 커밋하지 않고, Cloudflare Worker의 secret으로만 관리합니다.
- 브라우저는 사용자가 입력한 토큰을 `localStorage`에만 저장하며, 저장 요청 때마다 `Authorization` 헤더로 전송할 뿐 코드에는 남지 않습니다.
- 조회(`GET /state`)는 의도적으로 공개되어 있고, 저장(`POST /state`)만 토큰으로 보호됩니다.
